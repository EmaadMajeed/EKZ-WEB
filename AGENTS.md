# Project instructions

- Use `EmaadMajeed/EKZ-WEB` on GitHub for development and version control during the current phase.
- Keep the site compatible with Cloudflare Workers. Cloudflare remains the intended hosting platform for `ekztechnologies.com`.
- Defer adding or updating the Cloudflare API token and deploying to Cloudflare until the end of development. Use `.cloudflare.env` for the token and keep that file out of GitHub.
